## 🌟 Featured Project

### 📚 StudyFlow — AI-Powered Task Management with Full Kubernetes Deployment

> **The most complete DevOps project in this profile.** Full-stack app with React + Node.js + MongoDB, deployed on Kubernetes with auto-scaling, Nginx reverse proxy, and Google Gemini AI integration.

**[→ View Repository](https://github.com/Arulraj25/StudyFlow---Smart-Task-Management-with-AI)**

```
GitHub Push → Docker Build → Minikube → Kubernetes Pods → Nginx → Application
                                              ↓
                                    HPA Auto-Scales on Load
                              (2 → 5 replicas at 70% CPU)
```

**What makes this special:**

| Area | Implementation |
|---|---|
| 🤖 **AI Integration** | Google Gemini API — breaks complex tasks into subtasks, suggests priorities |
| ☸️ **Kubernetes** | Namespaces · ConfigMaps · Secrets · Deployments · Services · Ingress |
| 📈 **Auto-Scaling** | HPA scales backend 2→5 replicas at 70% CPU, frontend 2→5 at 70% CPU |
| 🐳 **Docker** | Multi-stage Dockerfiles for React + Node.js, Docker Compose for local dev |
| 🗄️ **Database** | MongoDB with persistent volume claims in Kubernetes |
| 🔐 **Security** | JWT authentication · Kubernetes Secrets for API keys · CORS config |
| 🌐 **Proxy** | Nginx reverse proxy routing frontend ↔ backend traffic |

`React` `Node.js` `MongoDB` `Google Gemini AI` `Docker` `Kubernetes` `Minikube` `HPA` `Nginx` `JWT` `Tailwind CSS`
